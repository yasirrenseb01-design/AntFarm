สารบัญทุกข้ออยู่ที่ `docs/LESSONS.md` — เพิ่มข้อใหม่ที่นี่แล้วเพิ่มบรรทัดในสารบัญด้วย


11g. **เพิ่มสิ่งกีดขวาง แล้วไม่ลองเดินจริง** (v0.11.49: เข้าบ้านแล้วเดินไม่ได้เลย)

12. **ข้อความไทยหรือเครื่องหมายพิเศษพังใน heredoc ของ bash**

    - กัน: สคริปต์แก้ไฟล์ที่มีภาษาไทย ให้เขียนเป็นไฟล์ .py ด้วย Write แล้วรัน (`PYTHONUTF8=1` ถ้าจำเป็น)

    - กัน: ก่อนปล่อยเวอร์ชันดู `git ls-files '*.gd' '*.py' | xargs wc -l | sort -rn | head` — เกิน ~500 แยกทันที (ดู WORKFLOW)
14. **แก้โค้ดด้วย Python ใน heredoc ของ bash แล้วเครื่องหมาย backslash เพี้ยน** (v0.8.63)
    - บรรทัดที่ต่อด้วย backslash กลายเป็นบรรทัดเดียวยาวคั่นด้วย tab หรือกลายเป็นตัวอักษร "\n" (ข้อนี้เองก็เพี้ยนตอนเขียนครั้งแรก)
    - กัน: โค้ดหรือข้อความที่มี backslash ให้แก้ด้วยเครื่องมือ Edit/Write; หลังแก้ไฟล์ .gd ให้หาบรรทัดที่ถูกต่อกัน
      (`grep -nP` หา "ตัวอักษร ช่องว่าง แล้ว tab กลางบรรทัด")
    - v0.11.41 ซ้ำอีก: `\\n` ในสคริปต์ Python ที่ส่งผ่าน heredoc กลายเป็นขึ้นบรรทัดจริงใน `strings.csv` (คำแปลหาย ขึ้นเป็นรหัส) แล้วสคริปต์แก้
      ที่ `open(p, 'w')` ก่อนโค้ดที่ error **ลบไฟล์ทั้งไฟล์** (คืนจาก git) — กัน: สคริปต์ที่มี backslash เขียนเป็นไฟล์ด้วย Write ใช้ `chr(92)`;
      สร้างสตริงที่จะเขียนให้เสร็จก่อนแล้วค่อยเปิดไฟล์เขียน
15. **ไฟล์ที่เกมอ่านจาก `user://` เชื่อไม่ได้ — ตัวอ่านของ Godot บางตัวสร้างของจริงจากข้อความ** (v0.11.15, ตรวจความปลอดภัย R8)
    - `ConfigFile.load` อ่าน `Resource("x.gd")` / `Object(...)` แล้ว**โหลดสคริปต์และรัน `_static_init()`** ทันที; ลิสต์ซ้อนหลายพันชั้นทำให้แครช (stack หมด);
      เซฟบอกความยาวเองแล้ว `get_var` จองหน่วยความจำตามนั้นก่อน; ค่าผิดชนิดในเซฟทำให้โหลดหยุดกลางทางเหลือรังครึ่งเดียว
    - กัน: ไฟล์ใหม่ที่เกมอ่านจาก `user://` ให้ผ่านทางเดียวกับที่มี (`Store._settings_file`, `Store.load_slot` + `save_check.gd`, `Store.meta`)
      หรือใช้ `bytes_to_var`/`JSON` (ไม่สร้าง object) + จำกัดขนาด + ตรวจชนิดก่อนใช้; ห้าม `ConfigFile.load`/`str_to_var`/`load()` กับไฟล์ใน `user://` ตรงๆ;
      เพิ่มกรณีใน `tests/save_fuzz_test.gd` (ต้องไม่มี script error เลยแม้แต่ครั้งเดียว — นับด้วย `Logger`)

24. **แก้ไฟล์ด้วย Python โดยใช้ตำแหน่ง (index) ที่หาไว้ก่อนแทรกข้อความอื่น** (v0.11.33)
    - หา `i, j` ของบล็อกใน shader แล้วแทรกฟังก์ชันใหม่ไว้ข้างบนก่อน จากนั้นตัดด้วย `s[:i] + new + s[j:]` — ตำแหน่งเลื่อนไป บล็อกเดิมค้างอยู่ครึ่งหนึ่ง
    - กัน: แทนที่ด้วยข้อความที่ไม่ซ้ำ (`assert s.count(a) == 1`) หรือหาตำแหน่งใหม่หลังแก้ทุกครั้ง; ดู `git diff --stat` ว่าจำนวนบรรทัดสมเหตุสมผล
25. **"หาสาเหตุไม่เจอเพราะตอนเทสไม่เกิด" — มดทั้งตัวค้างในดินหลายวินาที** (ผู้เล่นเห็นมานาน, แก้ v0.11.35)
    - ต้นเหตุ: เวรเลียตัวเพื่อน (ใหม่ v0.11.9) จ้างมดที่เกาะผนัง → ตอนเดินไปหาเพื่อน "วางบนพื้น" หาพื้นไม่เจอแล้วยกตัว 0.45 ทุกเฟรม

    - กัน: ผู้เล่นเห็นสิ่งที่ทำซ้ำไม่ได้ → **คัดลอกเซฟที่ผู้เล่นเล่นอยู่ล่าสุด** ไป `growtest/<ชื่อใหม่>` แล้วรันตัวจับเฉพาะเรื่องนั้นหลายรอบ
      (`--buried` เก็บประวัติ 150 เฟรมของตัวที่ค้าง); ฟังก์ชันที่ "หาไม่เจอแล้วคืนค่าเดิม" (`_floor_y`) ผู้เรียกต้องเช็กว่าเจอจริง

26. **ตัวเลขการวัดภาพในรังแกว่งมากระหว่างรอบ และเผลอแก้สคริปต์ตอนการวัดกำลังรัน** (v0.11.65)
    - ภาพในรังใช้ `randf()` (ไม่ deterministic) — seed เดียวกันวัดสองรอบ "เท้าลอย" ต่างกันได้ 2 เท่า, "เลียอากาศ" ต่อรังเป็น 0% หรือ 100%;
      6 รังยังแกว่ง ±0.5% ซึ่งพอๆ กับเป้า 2% → วัด **12 รัง** และวัดก่อน/หลังด้วยชุด seed เดียวกัน อย่าเทียบกับตัวเลขรอบเก่า
    - Godot โหลดสคริปต์ใหม่ทุกครั้งที่เปิด: แก้ไฟล์ระหว่างที่รันวัดหลาย seed ต่อกันในพื้นหลัง → seed หลังๆ วัดโค้ดคนละชุด (หรือ parse error)
      → รอให้รันเสร็จก่อนแก้ หรือแก้เฉพาะไฟล์ที่ไม่ได้ใช้ (docs)
    - เก็บ dictionary ของมดไว้ในอีกตัว (`m.ant_with = o` และ `o.ant_with = m`) → ทั้งสองอ้างถึงกัน `Array.has`/`==` วนไม่จบ ("Max recursion
      reached") → เก็บเป็นรหัส (`wid`) แล้วหาเอา

27. **ตัววัด "มดยืนนิ่ง" ที่นับมดเดินผ่านและมดสองตัวที่ทับกัน แล้วไล่แก้ตามตัวเลขผิดสามรอบ** (v0.11.66)
    - ตัววัดหน้าต่าง 1 วินาที นับทุกเฟรมตั้งแต่หน้าต่างเริ่ม มดที่เดินผ่านเลยถูกนับเป็น "ยืน" ช่วงต้นของทุกหน้าต่าง; จับคู่มดข้ามเฟรมด้วยตำแหน่งใกล้สุด
      มดสองตัวที่วาดทับกันเลยถูกสลับกัน ขาของคนละตัวกลายเป็น "เท้ากระโดด" → ได้ "มดพักยกขา 11 ครั้ง/วินาที" ทั้งที่จริง ~1.4;
      แก้ไปสามรอบ (กันก้าวตอนโดนดัน, กรองระยะเดิน, hysteresis เดิน/หยุด) โดยตัวเลขไม่ขยับ เพราะสิ่งที่วัดไม่มีจริง
    - กัน: ก่อนแก้ ให้พิมพ์ตัวอย่างดิบ "รายตัว รายเฟรม" ของกรณีที่ตัววัดบอกว่าแย่ (`STILLDBG=1`) แล้วอ่านดูว่าเป็นสิ่งที่ผู้เล่นเห็นจริงไหม;
