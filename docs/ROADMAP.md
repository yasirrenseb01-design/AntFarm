# AntFarm — แผนงาน

## เป้าหมาย
เกมจำลองการเลี้ยงมดที่สมจริงที่สุดเท่าที่ทำได้ ทำทีละส่วน เริ่มจากมดดำสวน *Lasius niger* ก่อน แล้วค่อยเพิ่มสายพันธุ์อื่น

## สองโหมดการเล่น
| โหมด | เป็นอย่างไร | ผู้เล่นทำอะไรได้ |
|---|---|---|
| **Desktop (พื้นหลัง)** | รังมดรันเป็นวอลเปเปอร์อยู่หลังไอคอนบนเดสก์ท็อป กินทรัพยากรน้อย | แค่จิ้มเบาๆ เช่น จิ้มมดให้ตกใจ จิ้มหยดน้ำหวาน |
| **Game (เข้าเกม)** | หน้าต่างเกมเต็มรูปแบบ | ให้อาหาร ปรับอุณหภูมิ/ความชื้น ดูภาพตัดรัง ขยายรัง ดูสถิติ |

ทั้งสองโหมดใช้การจำลองชุดเดียวกันและเซฟไฟล์เดียวกัน การจำลองต้องเดินต่อเนื่อง และตอนที่ปิดโปรแกรมต้องคำนวณย้อนหลังให้ (offline catch-up)

## Engine
- **Godot 4.7.2** (`E:\Godot_v4.7.2-stable_win64.exe`, รุ่นมาตรฐาน GDScript ไม่ใช่ .NET)
- ในเครื่องมี `dotnet` สำหรับทำตัวช่วย Win32 แยกต่างหากได้
- โหมดวอลเปเปอร์บน Windows: เอาหน้าต่าง Godot ไปเกาะกับหน้าต่าง `WorkerW` ของเดสก์ท็อป (เทคนิคเดียวกับ Wallpaper Engine/Lively) โดยใช้ตัวช่วยเล็กๆ ที่รับ HWND จาก `DisplayServer.window_get_native_handle()`
- การจิ้มบนเดสก์ท็อป: ไอคอนเดสก์ท็อปจะบังเมาส์ไว้ ตัวช่วยต้องดักคลิกบนพื้นที่ว่างของเดสก์ท็อป (low-level mouse hook) แล้วส่งพิกัดเข้าเกม
- ทางสำรองถ้าวอลเปเปอร์มีปัญหา: หน้าต่างโปร่งใสแบบ desktop pet ที่คลิกทะลุได้ ยกเว้นตรงตัวมด

## ข้อมูลชีววิทยาที่ใช้ (Lasius niger)
- รังมีราชินีตัวเดียว (monogyne) ราชินีก่อตั้งรังแบบ claustral
- ไข่ ~10 วัน, ตัวอ่อน ~13 วัน, ดักแด้ ~11 วัน ที่ ~28°C; การพัฒนาหยุดต่ำกว่า ~13°C
- มดงานอายุน้อยดูแลตัวอ่อน มดอายุมากออกหาอาหาร
- ตัวอ่อนต้องการโปรตีน ตัวเต็มวัยใช้น้ำตาล (เช่นน้ำหวานจากเพลี้ยอ่อน)
- ดักแด้อยู่ในรังไหม (cocoon)
