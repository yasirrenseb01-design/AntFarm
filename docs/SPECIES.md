# เพิ่มมดสายพันธุ์ใหม่

ผู้เล่นถาม (2026-10-27): ถ้าทำสายพันธุ์ใหม่ การเดิน ระบบกันชน และงานภาพจะยากเหมือนเดิมไหม — คำตอบ: ส่วนใหญ่เป็น**ตัวเลข**ในไฟล์เดียว
ส่วนที่ยังต้องทำเองคือ**โมเดล**ใน Blender และ**ข้อมูลชีววิทยาพร้อมแหล่งอ้างอิง**

## ขั้นตอน
1. คัดลอก `scripts/sim/species/lasius_niger.gd` เป็นไฟล์ใหม่ (เช่น `formica_fusca.gd`) แก้ `DATA.id`, ชื่อ, ทุกค่าชีววิทยา
   (ระยะไข่/ตัวอ่อน/ดักแด้, อุณหภูมิ, อายุ, การกิน, ความเร็วเดิน, การตั้งรัง ...) — ทุกค่าต้องมีแหล่งใน `docs/BIOLOGY.md`
   และแยก "หลักฐาน" กับ "อนุมาน"
2. การ์ดหน้าเลือกสายพันธุ์ `CARD` + ข้อความใน `lang/strings.csv` (ไทย/อังกฤษ)
3. **`DATA.look`** — ภาพทั้งหมดอ่านจากที่นี่ ไม่มีที่อื่นเขียนตัวเลขของสายพันธุ์:
   - `worker_scale` — ความยาวมดงาน ÷ 4.2 มม. **ตัวเลขเดียวนี้ทำให้ทุกอย่างขยาย/ย่อตาม**: ตัวมด ช่วงก้าว (เท้าไม่ไถล)
     ระยะกันชนระหว่างมด (`outworld_crowd`, `nest_bodies`) ความสูงตอนปีนข้ามกัน/ลูกมด ที่ว่างเหนือหัวในอุโมงค์ — เพราะทุกระบบคิดจาก
     ขนาดตัวที่วาด (`ANT_SCALE × size`, `m.size`) ไม่ใช่ค่าคงที่ของ Lasius
   - `queen_scale` — ขนาดโมเดลราชินี
   - `worker_limbs`, `queen_limbs` — สีขา/หนวด/กราม อ่อนกว่าตัวเท่าไร
   - `models` — โฟลเดอร์โมเดลใน `assets/models/ants/<models>/` (`""` = Lasius niger)
4. ใส่ในรายการ `ALL` ของ `scripts/sim/species/registry.gd`
5. รัน `tools/check.ps1` — `tests/species_test.gd` ฟ้องถ้าลืมค่าใดที่สายพันธุ์แรกมี

## โมเดล (ส่วนที่ยังเป็นงานฝีมือ)
- `tools/blender/build_ant.py` สร้าง `worker_hi/lo`, `queen_hi/lo` — สายพันธุ์ที่**รูปร่างคล้าย** Lasius (Formicinae ส่วนใหญ่)
  แก้แค่สัดส่วน (หัว อก ท้อง ความยาวขา) แล้วส่งออกไปโฟลเดอร์ `models` ของมัน
- **ข้อควรระวัง:** การก้าวขาใช้ IK ใน shader ที่อ่านจุดข้อต่อจาก `tools/blender/ant/legs.py LEGS` (ต้องตรงกับใน `shaders/ants/ant_core.gdshaderinc`)
  ถ้าสายพันธุ์ใหม่**ขายาว/สั้นต่างจาก Lasius มาก** ต้องย้ายข้อต่อนี้เป็นค่าต่อสายพันธุ์ (uniform ต่อ material) — ยังไม่ได้ทำ
  (ตอนนี้ทุกสายพันธุ์ใช้ข้อต่อขาชุดเดียว)
- ถ่ายภาพตรวจการเดินถี่ๆ ทุกมุม (ข้าง/หน้า/บน/มองทะลุดิน) ด้วย `--feet`, `--bodies` ก่อนส่ง (docs/LESSONS.md)

## พฤติกรรม
- พฤติกรรมที่ต่างกันระหว่างสายพันธุ์ใช้ธงใน `DATA` (เช่น `founding`, `tends_aphids`, `buries_prey`) — โค้ดการจำลองอ่านธง ไม่ได้เช็คชื่อสายพันธุ์
  พฤติกรรมใหม่ที่ Lasius ไม่มี (เช่น มดทาสของ Formica sanguinea) ต้องเขียนโค้ดเพิ่มเป็นธงใหม่
- การจำลองเป็นความจริงหนึ่งเดียว: ทุกอย่างที่ผู้เล่นเห็น (มดขุด มดขนดิน) ต้องมีอยู่ในการจำลอง — ภาพห้ามสร้างมดขึ้นเอง (v0.11.57)
