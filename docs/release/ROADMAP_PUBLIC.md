# AntFarm: Legions of the Unseen — แผนหลังปล่อย Early Access

แผนนี้เรียงตามลำดับที่ตั้งใจจะทำ ยังไม่กำหนดวันที่ และอาจปรับตามเสียงตอบรับจากผู้เล่น

1. **ดูแลเกมหลังปล่อย** — แก้บั๊กที่ผู้เล่นเจอ แก้เกมกระตุกและค้าง ปรับการเดินของราชินีในอุโมงค์
2. **จอติดผนังในห้อง Home** — ซื้อจากร้านค้า ดูรังที่เลือกแบบสดๆ บนจอ
3. **ดินทำรังเต็มตู้ + รังหลักพันตัว** — ตอนนี้มดขุดได้แค่ดินช่วงกลางตู้ จะขยายให้ขุดได้ทั่วทั้งตู้ รังแผ่กว้างตามตู้ และรองรับมดมากขึ้นถึงหลักพันตัว
4. **รังโตเต็มวัยและการบินผสมพันธุ์** — ราชินีและตัวผู้มีปีก เก็บราชินีไปตั้งรังใหม่
5. **ฉากสวนเปิดโล่ง** — ไม่มีกล่องกระจก พื้นที่หากินกว้างขึ้น เหยื่อหลากหลายขึ้น
6. **สายพันธุ์ที่ 2: มดตัดใบ *Atta cephalotes*** — ตัดใบไม้ เพาะสวนเห็ด และมีมดหลายขนาดทำงานต่างกัน

จะมีด้วย แต่ยังไม่กำหนดลำดับ: **โหมดสร้างในห้อง Home** — จัดห้องเอง ย้ายและวางชั้นวาง ตู้มด และของต่างๆ บนตาราง พร้อมช่องเก็บของ
