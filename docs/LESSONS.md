# บทเรียนจากความผิดพลาด

**อ่านสารบัญนี้ทุกครั้งก่อนเริ่มงาน** แล้วเปิดไฟล์หมวดที่เกี่ยวกับงานรอบนั้นอ่านรายละเอียด
(แต่ละข้อมี **สิ่งที่พลาด → ต้นเหตุ → วิธีกันไม่ให้เกิดอีก**). เอกสารอื่นอ้างเป็น "LESSONS <เลขข้อ>" — เลขข้อเดิมไม่เปลี่ยน

ถ้าพลาดเรื่องใหม่: เพิ่มข้อในไฟล์หมวดนั้น **และ** เพิ่มบรรทัดในสารบัญนี้ ในรอบงานเดียวกัน (ไม่ใช่แค่แก้แล้วผ่านไป)

## การรันและทดสอบ — `docs/lessons/run_and_test.md`
- `1` Godot ค้างเป็นจอดำ
- `1b` ตัวตรวจรันทดสอบต่อทั้งที่ parse ไม่ผ่าน
- `2` ลบไฟล์เกมที่ต้องเก็บ
- `3` ตรวจท่าเดินจากภาพนิ่งภาพเดียว
- `3b` ตรวจความลื่นของท่าทางจากภาพห่าง ๆ
- `3c` เดาจากภาพว่ามดทำอะไร
- `3d` กฎการจำลองที่ตั้งใจให้รังเล็ก ไปโดนรังใหญ่ด้วย
- `3e` ตัดสินจากการวัดรอบเดียวในฉากที่สุ่ม
- `3f` ทดสอบความเร็วด้วยสถานการณ์ที่ผู้เล่นไม่เจอ
- `3g` วัดอาการ "กระตุก" ด้วยระยะที่ขยับต่อเฟรม
- `3h` จัดวางของตาม "ลำดับในรายการ" ทุกครั้งที่อัปเดต
- `3i` เพิ่มการตรวจต่อชิ้นในงานที่ทำซ้ำบ่อย โดยไม่ดูเวลา
- `3j` แก้อนิเมชันจากภาพมุมเดียวหรือจากการคิดเอา
- `3k` หาความช้าแค่ในโค้ดที่ตัวเองจับเวลา
- `3l` ตัววัดที่หลวมเกินบอกว่า "ไม่มีปัญหา"
- `3m` ตรวจของที่โตได้ด้วยขนาดตอนวาง
- `3n` วัดก่อน-หลังด้วยรอบเดียว
- `3o` ตัวนับที่จับคู่ผิดตัว
- `3p` ของที่ทำทุกเฟรมทุกตัวต้องดูตอนซูมออกด้วย
- `3q` ภาพทดสอบที่ถ่ายก่อนรังสร้างเสร็จ
- `3r` MultiMesh ที่ไม่ได้ตั้งสีต่อชิ้น
- `3s` แก้ภาพจุดหนึ่ง แล้วไม่ดูว่าทำอย่างอื่นเสียไหม
- `3t` ตัววัด "สั่น" ที่ละเอียดเกินตา
- `3u` ทำภาพต่างกันตามระยะกล้องเพื่อความเร็ว
- `3v` แก้ตามทฤษฎีที่ฟังดูดี แทนที่จะวัดก่อน
- `3w` ตัววัดที่นับสิ่งที่ผู้เล่นไม่เห็น
- `3x` สั่งหยุดที่ "ทาง" แต่ตัวที่วาดยังไหลต่อ
- `3y` ยกตัวก่อนขั้นที่ปรับความสูงอีกที
- `3z` งานจุกจิกต่อมดทุกตัวทุกเฟรม
- `4` ทดสอบความสมดุลด้วยสคริปต์ที่ป้อนอาหารให้
- `5` การทดสอบที่ผ่านทั้งที่ผิด
- `6` ผลจำลองต่างกันระหว่างเล่นต่อกับโหลดเซฟ
- `7` ไฟล์ Blender สร้างซ้ำได้ไฟล์ไม่เหมือนเดิมทุกไบต์
- `8a` วัดความเร็วผิดวิธี
- `8b` ระบบใหม่ครอบคลุมไม่ครบ
- `8c` แรงดันแยกวัตถุที่ไม่สะสม
- `8d` ทดสอบแค่ห้องใหญ่
- `8e` ปล่อยเวอร์ชันทั้งที่ตรวจไม่ผ่าน
- `37` ปรับสมดุลแล้วทดสอบแค่แบบที่ตั้งใจแก้ (รังป่าอดตายหลัง v0.12.0)

## ความสมจริง — `docs/lessons/realism.md`
- `8` ขนาดผิดจริงโดยไม่มีใครเห็น
- `9` ใช้รูปทรงหรือค่าที่ออกแบบให้ของชิ้นหนึ่งกับของอื่น
- `10` ระบบที่ตั้งค่าตาม "สัดส่วนของความจุ"
- `11a` ใช้ตัวนับที่ออกแบบไว้เรื่องหนึ่งมาตอบอีกเรื่อง
- `11b` ระบบที่ไม่เกิดเลยโดยไม่มีใครรู้
- `11c` งานจาก Cloud session ที่บอกว่า "แก้แล้ว" แต่ไม่เคยรันจริง
- `11d` ตัวเลขการจำลองจากเครื่องคลาวด์ (Linux) ไม่ตรงกับ Windows
- `11e` ขนาดเดียวกันเขียนไว้หลายที่ แล้วค่อยๆ ไม่ตรงกัน
- `11h` ขยายฉากทั้งฉาก แล้วค่าที่จูนเป็นเมตรพัง
- `11i` ภาพสร้างสิ่งที่การจำลองไม่มี
- `11` ทำงานเฉพาะหน้าจุดเดียวแล้วจุดอื่นตามมา

## เครื่องมือและการเขียนไฟล์ — `docs/lessons/tools_and_files.md`
- `11g` เพิ่มสิ่งกีดขวาง แล้วไม่ลองเดินจริง
- `11f` ปุ่มที่ไม่เคยมีใครกดในการทดสอบ
- `11e` ตัวตรวจทีละบรรทัดพลาดสตริงที่ขึ้นบรรทัดใหม่
- `12` ข้อความไทยหรือเครื่องหมายพิเศษพังใน heredoc ของ bash
- `13` ไฟล์โตเกินกฎโดยไม่รู้ตัว
- `14` แก้โค้ดด้วย Python ใน heredoc ของ bash แล้วเครื่องหมาย backslash เพี้ยน
- `15` ไฟล์ที่เกมอ่านจาก `user://` เชื่อไม่ได้ — ตัวอ่านของ Godot บางตัวสร้างของจริงจากข้อความ
- `16` ค้นหาของข้างเคียงด้วยตาราง แต่ของยาวกว่าช่องตาราง
- `17` ค่าที่นับวันละครั้ง แต่ของที่มันชี้หมดไประหว่างวัน
- `18` ตัวคลายกลับที่ไม่ดูว่าคลายแล้วจะชนอีก → ส่ายไปมา
- `19` ตัววัดเป็นเปอร์เซ็นต์ ตัวหารเปลี่ยนตามการแก้
- `20` การแก้พฤติกรรมเปลี่ยนฉากที่ใช้วัดความเร็ว
- `21` ตัวตรวจเซฟบังคับค่าที่ตัวโหลดอ่านแบบมีค่าเริ่มต้น
- `22` ตัววัด "ต่อเฟรม" วัดตอนเกมช้าเพราะตัววัดเอง
- `23` ตัววัดอ่านค่าผิดช่องหลังเพิ่มช่องใน array
- `24` แก้ไฟล์ด้วย Python โดยใช้ตำแหน่ง (index) ที่หาไว้ก่อนแทรกข้อความอื่น
- `25` "หาสาเหตุไม่เจอเพราะตอนเทสไม่เกิด" — มดทั้งตัวค้างในดินหลายวินาที
- `26` ตัวเลขการวัดภาพในรังแกว่งมากระหว่างรอบ และเผลอแก้สคริปต์ตอนการวัดกำลังรัน
- `27` ตัววัด "มดยืนนิ่ง" ที่นับมดเดินผ่านและมดสองตัวที่ทับกัน แล้วไล่แก้ตามตัวเลขผิดสามรอบ
- `28` Dictionary ของมดใช้เป็น key / เทียบด้วย `has` อีกแล้ว
- `29` ตัววัด "ลูกมดซ้อน" ที่วัดความสูงจากพื้นใต้แต่ละชิ้น
- `30` ตัวตรวจเซฟเทียบกับรังแบบเดียว ทำให้เซฟรังใหญ่ทิ้งทุกครั้ง
- `31` ตัวเลือกบรรทัดคำสั่งถูกอ่านซ้ำทุกครั้งที่โหลดฉากใหม่
- `32` หน้าที่ถูกซ่อนยังทำงานอยู่ข้างหลังหน้าอื่น
- `33` วัดรังผิดตัวโดยไม่รู้ และรายงานผู้เล่นไปแล้วว่าเป็นรังเขา
- `34` ตัววัด "จมดิน" ดีขึ้น แต่ราชินีพลิก 176 องศาในเฟรมเดียว
- `35` เปิดระบบเดิมให้ทำงานต่อในหน้าใหม่ แล้วไม่ลองเล่นบนหน้านั้น
- `36` เก็บ "สำเนา" ของ PackedArray ด้วยการกำหนดค่า แล้วมันเปลี่ยนตามต้นฉบับ
