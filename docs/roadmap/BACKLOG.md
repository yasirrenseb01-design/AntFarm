  - **ปุ่มขวาของแถบบน ("ศัตรู" "รังของฉัน" "วอลเปเปอร์") ถูกแผงข้างขวาบังที่หน้าต่างกว้าง 1600** (กว้าง 1920 เห็นครบ) — มีมาก่อน

- **EA3a — ตกลงกับผู้ใช้ 2026-10-20 (ทำสองรอบ):**
  - **การจำลองเป็นคนเลือกว่ามดตัวไหนทำอะไร ("เวรงาน")** ไม่ใช่ฉากภาพสุ่มเอง: ทุก ~30 นาทีในเกม มดในรังแต่ละตัวได้เวร —
    ป้อนตัวอ่อน / คาบลูกมด / ป้อนน้ำหวานเพื่อน (จับคู่ผู้ให้→ผู้รับเป็นรายตัว) / ล้อมราชินี / แต่งตัว / ยืนพัก / ขุด
    เลือกจาก `task` + เกณฑ์รายตัว `threshold()` + สถานะรัง; ใช้ `sim.rng` (deterministic, เดินตอนปิดเกม)
  - **เวรมีผลจริง** (ผู้ใช้เลือก): เช่น ตัวอ่อนที่ได้ป้อนน้อยโตช้า/ตายง่าย, มดที่ได้น้ำหวานจากเพื่อนมีแรง (`energy`) — แต่**อาหารยังเป็นของรวม**
    (`sugar`/`protein`/`fat`; กระเพาะพักรายตัวยังเลื่อนไปหลัง EA) → ผล self-test เปลี่ยนแน่ ต้องจูนให้การเติบโตของรังใกล้เดิม (year_run เทียบ v0.11.7)
  - **สัดส่วนเวรต้องมาจากงานวิจัยก่อน** (ผู้ใช้เลือก): ตาราง [Ln]/[ญาติ]/[อนุมาน] ใน `docs/BIOLOGY.md` ให้ผู้ใช้ดูก่อนเขียนโค้ด
  - ตัวนับรายตัว (เซฟ v10): ป้อนตัวอ่อน, คาบลูกมด, ป้อนเพื่อน, ยืนพัก (เวลา), ขุด (เวลา), ขนน้ำหวาน (เที่ยว), ขนเหยื่อ, ขนศพ, รุมศัตรูแล้วรอด;
    อันดับ: ใหญ่/เล็ก/อายุมากสุด + ทุกตัวนับ + บาดเจ็บแต่ยังรอด (`hurt`)
  - **ตั้งชื่อราชินี** (ชื่อในเซฟ, แจ้งเตือนตอนตายแบบมดงาน, กล้องหน้าแรกตามได้) + **รายชื่อมดที่มีชื่อ** (ราชินีบนสุด) ในแท็บ
  - แท็บ "มดเด่น" (ปุ่มแถบบน แผงแบบแผงศัตรู): อันดับ 1 แต่ละด้าน + รายชื่อ; "ไปดู" = สลับมุม + เลือกตัว + กล้องเกาะตาม
  - **รอบ 1:** เวร + ผลของเวร + ตัวนับ + แท็บ + รายชื่อ + ชื่อราชินี (ฉากรังยังเล่นท่าแบบเดิม) → ผู้ใช้ลอง;

  - แบ่งงาน: **Cloud** = ค้นงานวิจัย (ส่งตารางก่อน) แล้วฝั่ง sim ทั้งหมด (เวร ผล ตัวนับ ชื่อราชินี เซฟ v10 + migration + เทสต์ + จูน year_run,
    แยก `sim_base.gd` ที่เกิน 500 บรรทัด, ฟังก์ชันข้อมูลอันดับ `sim.top_ants()`); **session บนเครื่อง** = แท็บ/ไปดู/ช่องชื่อราชินี (UI) + รอบ 2 ทั้งหมด

- PART 3: ความชื้นในดินแต่ละจุด (ตัวอ่อนย้ายตามความชื้น); หน้าตัดตู้แอนท์ฟาร์มยังเป็นเหลี่ยมบางจุด
