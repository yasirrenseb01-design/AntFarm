## PART EA เตรียม Early Access (ผู้ใช้ 2026-10-20) — ประเมินจากโค้ด v0.11.0
- **EA1 วอลเปเปอร์:** ตอนนี้ปุ่ม "วอลเปเปอร์" เซฟแล้วเปิดเกมใหม่ด้วย D3D12 + `--desktop`; กลับเข้าเกม (`leave()` → `_restore_window`)
  คืนค่าหน้าต่างที่จำไว้ตอนเปิดใหม่ ไม่ใช่หน้าต่างก่อนกดปุ่ม และเกมยังรันบน D3D12 ต่อ — ผู้ใช้ยืนยัน 2026-10-20: **ขอบหน้าต่างหาย**
  (ไม่มีปุ่มปิด/ย่อ) ทางแก้ที่คิดไว้: ส่งขนาด/ตำแหน่ง/โหมดหน้าต่างเดิมผ่านบรรทัดคำสั่งตอนเปิดใหม่,
  ปุ่ม "เป็นวอลเปเปอร์" ในเมนูถาดระบบ (สลับไปกลับได้), คลิกไอคอนถาดครั้งเดียว = กลับเข้าเกม, ปุ่มปิดเกมในหน้าเกม
- **EA2 หน้าเริ่มเกม:** ตอนนี้เปิดเกมเข้ารังล่าสุดทันที (`main.gd` อ่าน `_settings.slot`), เลือกรัง/รังใหม่อยู่ในหน้าต่าง "รังของฉัน"
  (`hud_colonies.gd`) → ทำหน้าแรก: เล่นต่อ / รังใหม่ (ฉาก + แถบสัตว์ร้าย EA4) / รังของฉัน / ตั้งค่า / วอลเปเปอร์ / ออก
  ลบ 2 มิติ: ปุ่ม `["มุมบน 2 มิติ", "surface"]` ใน `hud_controls.gd`, `mode := "surface"` เป็นค่าเริ่มใน `main_base.gd`,
  `view/surface2d/world_view.gd` + `ant_batch.gd` + Camera2D — **ระวัง:** `draw_kit.gd` ยังใช้วาดมดใน HUD (`hud_panel.gd`) ห้ามลบ;
  มี `"surface"` ~46 จุดในโค้ด, ตัวเลือก dev `--view=surface`/`--shot` อาจใช้ 2D อยู่
- **EA3b ตั้งชื่อมด** (ผู้ใช้ 2026-10-20: แยกจากมดเด่น): ตั้งชื่อมดตัวไหนก็ได้ ไม่จำกัดจำนวน (คลิกมด → กล่อง `ant_tip` มีช่องตั้งชื่อ),
  ชื่อเก็บใน Ant (`name`, เพิ่มใน `ANT_FIELDS` + migration), มดที่มีชื่อตาย → แจ้งเตือน (บันทึก + เสียง/ป้ายเด่น พร้อมสาเหตุจาก `_kill`)
- **EA3a มดเด่นในรัง:** ข้อมูลที่มีใน sim แล้ว: `ant.size` (ใหญ่/เล็กสุด — ง่าย), `foe`/`hurt` (นับ "สู้แล้วรอด" ได้ใน `_release`/`_shake_off`
  — ง่าย), `id`. **ปัญหา:** ขนไข่/ตัวอ่อน, ยืนพัก, ป้อนอาหารเพื่อน (trophallaxis) เกิด**ในชั้นภาพ** (`nest_mates.gd`, `nest_rest.gd`)
  เท่านั้น — นับตรงนั้นจะได้แค่ตอนเปิดดูในรัง ไม่ deterministic ไม่เดินตอนปิดเกม → ต้องให้ sim สุ่มว่ามดตัวไหนทำ
  (จาก `task` + เกณฑ์รายตัว `threshold()`, ใช้ `sim.rng`) แล้วชั้นภาพเลือกตัวที่ sim บอกมาเล่นท่า
  ต้องเพิ่มใน Ant: `name`, ตัวนับ (`n_brood`, `rest_t`, `n_feed`, `n_fights`) → `SAVE_VERSION` + `save_migrations.gd`
  กดในแท็บแล้วไปหา: มี `nest_view.focus()` และ `ant_tip` เลือกมดได้แล้ว (ถ้ามดอยู่ข้างนอกต้องสลับไปมุมพื้นดิน)
  อาหารส่วนตัว (กระเพาะพักรายตัว): **ยาก** — sim เก็บน้ำหวาน/โปรตีน/ไขมันเป็นของรวม (`sugar`, `protein`, `fat`) การเปลี่ยนกระทบ
  การอดตาย/จำศีลทั้งระบบ → เลื่อนไปหลัง EA
- **EA4:** ความถี่ศัตรูอยู่ใน `STATS.rate` (ต่อวัน: แมงมุม 0.25, ตะขาบ 0.3 กลางคืน, ด้วง 0.18 กลางคืน) × `season_life()` และมีได้ทีละตัว
  → เพิ่มตัวคูณ `enemy_rate` (0 = ไม่มี .. 300%) เก็บในเซฟ ตั้งตอนเริ่มรัง (และปรับทีหลังในตั้งค่า?) ข้อความ "≈ ทุก N วันในหน้าร้อน"
  **ต้องทำพร้อมกัน — ศัตรูธรรมชาติพังมาตั้งแต่ v0.8.25** (พบตอนทำ EA5): `blocked()` นับแถบ 3 px ริมขอบเป็นกำแพง แมงมุม (0.55 px/tick)
  และด้วงที่เดินเข้ามาจากนอกกล่องจึงหันกลับที่ขอบทุกครั้ง ไม่เคยเข้ามาเลย (ตะขาบเร็วพอข้ามได้) — v0.11.1 แก้เฉพาะตัวที่ผู้เล่นปล่อย
  (`released`) เพราะลองแก้ทั้งหมดแล้ว รังสวนไม่ดูแล 14 ตัว (seed 5) ปีแรกค้างที่ ~11–16 ตัว (เดิมโตถึง ~70) ตายเพราะศัตรู 68 ตัว:
  อัตราเกิดต่อวัน (แมงมุม 0.25, ตะขาบ 0.3, ด้วง 0.18) แทบทุกวัน และรัง <20 ตัวมดหลบไม่สู้ → ปรับอัตรา (ทั้งปีจริง ๆ แมงมุมหมาป่า
  ล่ามดเป็นครั้งคราว) แล้วใช้กฎ `inside` แบบใหม่ (ตำแหน่งปัจจุบัน) กับทุกตัว, ทดสอบ `year_run wild` ทั้ง kept/alone หลาย seed
  ด้วงดินที่ปล่อย: รัง 60 ตัวมดฆ่ามันได้ 5/8 ครั้งและเสีย ~8 ตัวต่อครั้ง (คอมเมนต์ในไฟล์บอก "มดมักฆ่าไม่ได้") — ดูค่าพลัง/เกราะด้วย
- **EA5 แท็บศัตรู: ทำแล้ว v0.11.1** — ที่ยังไม่ได้ทำ: ปล่อยในตำแหน่งที่คลิก (ตอนนี้เข้าจากขอบสุ่ม), ภาพละอองสารเคมีตอนด้วงพ่น (PART 6),
  ศัตรูเข้าไปในรัง, หลอดพลังลอยเหนือตัวศัตรูในฉาก 3 มิติ (ตอนนี้บอกเป็นตัวเลขในแผง)

## งานค้าง (เรียงตามส่วน)
- PART 3: ความชื้นในดินแต่ละจุด (ตัวอ่อนย้ายตามความชื้น); หน้าตัดตู้แอนท์ฟาร์มยังเป็นเหลี่ยมบางจุด
- PART 5: มดปีนข้ามใบไม้/กิ่งไม้/หิน (การจำลองต้องรู้ความสูงพื้น); การกลบดินยังเป็นแค่ภาพ (ยังไม่มีผลกับการเน่า/การแย่งอาหาร);
  มดช่วยกันลากขาที่หลุด; ใบถั่วบางมุมเห็นเป็นแผ่นแบน; มดในรังบางทีเดินทับฉากอนิเมชัน
- PART 6: มดรังอื่น (มดถนน *Tetramorium* ยกทัพ, Lasius รังข้างเคียง) — ศัตรูหลักในธรรมชาติ แต่ในกล่องปิดแทบไม่เกิด
  และต้องจำลองรังที่สองทั้งรัง (ผู้ใช้ถาม 2026-10-11 ผมแนะนำให้เลื่อนไปก่อน); ศัตรูบุกเข้าไปในรัง; มดลากผู้บาดเจ็บกลับรัง;
  แมงมุมกระโดด (Salticidae) ที่อยู่ในแผนเดิม; ภาพละอองสารเคมีตอนด้วงดินพ่น
- เครื่องมือ: `mesh_kit.gd` ยังมีโมเดลสำรองแบบเก่า (ลบได้เมื่อย้ายครบ)
- PART 7: หิมะ, จำลองช่วงปิดเกมข้ามหน้าหนาวให้เร็วขึ้น, มดรวมกันห้องลึกตอนหนาว, ฝ้าบนกระจกตอนอยู่ในตู้เย็น,
  ห้องเกิดจากที่มดย้ายลูกมดไปจริงๆ (ตอนนี้ใช้แผนที่ให้ผลแบบเดียวกัน), ตู้กระจกห้องข้างกันยังต่อกันเป็นแนวยาว

- PART 8: ขาราชินีกว้างกว่าห้องก่อตั้งรังเล็กๆ; เศษเหยื่อในกองตัวอ่อนยังไม่กันชน;
  มดที่เดินผ่านกองลูกมดยังเฉียดทับได้บ้าง (ลดลงครึ่งหนึ่งใน v0.8.17; ที่เหลือคือกองขวางทางหรือหลบไม่ทัน);
  กรณีแย่สุด (300 ตัวอัดในรังเล็ก มุมราชินี) ยัง ~26 FPS — การ์ดจอ (โมเดลมด lo ~1,570 จุด × รอบเงา) และกันชนตอนเบียดกันมาก
- **รังสวนแบบไม่ดูแลอดตายหมู่หน้าหนาว** (พบ 2026-10-12, v0.8.19 `year_run wild ... alone 3/4`): ตัวอ่อนที่ข้ามหนาว
  ออกเป็นมดงานพร้อมกันในหน้าร้อน (เช่น 14 → 115 ตัว) แต่ใบไม้ร่วงน้ำหวานน้อย สะสมไขมันไม่พอ → ไขมันหมดเดือนธันวาคม
  มดตายเกือบหมด (มีมาก่อน v0.8.19) — ที่อาจขาด: รังลดตัวอ่อน/กินตัวอ่อนเมื่ออาหารไม่พอช่วงใบไม้ร่วง, เก็บไขมันตั้งแต่ปลายหน้าร้อน

## ไอเดียที่ผู้ใช้ฝากไว้ (ยังไม่จัดเข้า PART)
- **กองลูกมดแบบวงซ้อน** (จากงานวิจัย 2026-10-12, Franks & Sendova-Franks 1992): กองเดียว ไข่+ตัวอ่อนเล็กตรงกลาง
  ตัวอ่อนโตอยู่วงนอกห่างกันกว่า แทนกองแยกข้างกัน (ต้องเช็กว่า *Lasius* ทำแบบนี้ด้วยไหม; รังไหมมักแยกห้องที่แห้งกว่าอยู่แล้ว)
- **มดซ้อนกันที่ยังเหลือ (v0.8.56):** ปีนข้ามกันในอุโมงค์แคบแล้ว; ยังเหลือห้องที่แน่นจริงๆ — ทางเลือก: พักซ้อนบนหลังกันเป็นกอง
  ตอนหน้าหนาว (มดจริงทำ); (งอซ้าย-ขวาตอนเลี้ยวแล้ว v0.8.57)
- **ตัวอ่อน/รังไหมที่วางคร่อมแนวตัด** ยังวาดอยู่ (มดที่คร่อมแนวตัดซ่อนแล้ว v0.8.57)
- **มดตรงมุมห้อง/รอยต่อพื้นกับผนัง (v0.8.56):** ช่องที่ "ขึ้น" เป็นแนวเฉียง ตัวมดยังลอยจากผิวเล็กน้อย (รัง 60 ตัว ~5 จาก 20 ตัว
  ยืนห่างพื้น >0.35) — อาจให้มดพักบนพื้นหรือผนังด้านใดด้านหนึ่งแทนแนวเฉียง
- **ห้องแน่น (รัง ~40 ตัว ห้องเล็ก):** มดเดินผ่านกันยังซ้อน ~5–9 คู่ต่อเฟรม (มีมาก่อน v0.8.22) — รังควรขยายห้องเร็วขึ้นเมื่อแน่น?
- **กระเพาะพักรายตัว:** การจำลองยังเก็บน้ำหวาน/โปรตีนเป็นของรวม — กล่องสถานะจึงบอกได้แค่ "กระเพาะพักเต็ม" ตอนขนกลับ
- **ดินในรังให้เหมือนดินจริง** (ผู้ใช้ 2026-10-12): ชั้นดินตามความลึก (ดินร่วนดำข้างบน, ดินเหนียว, ทรายข้างล่าง), เม็ดทราย/กรวดในผนัง,
  ผนังที่มดอัดเรียบ, รากพืช, ความชื้นทำให้สีเข้ม
- **สัตว์ในดิน** (ผู้ใช้ถาม 2026-10-12): ไส้เดือนไชดินผ่าน (มดไม่กิน แต่เจอระหว่างขุด), แมลงหางดีด/ไร (เหยื่อจริงของมดดำสวนในดิน)
- **กองดินปากรังถูกฝนกัดเซาะ** (ผู้ใช้สังเกต 2026-10-12: ปากรังสูงขึ้นเรื่อยๆ) — ในธรรมชาติฝนและลมทำให้กองดินแบนลง มดซ่อมใหม่
- **การกลบเหยื่อมีผลจริง** (ผู้ใช้ถาม 2026-10-12) — ตอนนี้เป็นแค่ภาพ มดยังไม่ได้ขนดินมากลบจริง
- **ฉากเมือง** (ผู้ใช้ 2026-10-11): มดดำสวนเป็นมดที่พบบ่อยที่สุดในเมืองของยุโรป — รังใต้แผ่นทางเท้า/รอยแตกพื้นปูน/ข้างถนน,
  เข้าบ้านหาของหวาน; อาหารจากเศษขนมปัง/น้ำหวานที่คนทำหก + เพลี้ยตามต้นไม้ริมทาง, ผู้ล่าน้อยกว่าในสวน,
  อุ่นกว่าชนบท (urban heat island) ออกหากินได้นานกว่าในแต่ละปี — เป็นตัวเลือกฉากที่สาม

- **ฉากแบบผสม** (ผู้ใช้ 2026-10-11): ชุดเลี้ยงที่มีบางอย่างจากธรรมชาติ — ยังไม่ทำ
