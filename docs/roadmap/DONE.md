# ส่วนงานที่เสร็จแล้ว — รายละเอียด

ย้ายมาจาก `docs/ROADMAP.md` (v0.8.6) เมื่อ PART เสร็จ ให้ย้ายรายละเอียดมาไว้ที่นี่ ใน ROADMAP เหลือบรรทัดเดียว
รายละเอียดทีละเวอร์ชันอยู่ใน `CHANGELOG.md`

1. **[x] แกนการจำลอง + ภาพพื้นที่หาอาหาร** (รุ่นแรกเสร็จ 2026-10-10 · renderer: Mobile/Vulkan เพราะ Compatibility ไม่มี 2D MSAA) — ระบบจากต้นแบบเว็บเขียนใหม่เป็น GDScript: ฟีโรโมน, มดออกหาอาหาร, วงจรไข่→ตัวอ่อน→ดักแด้→มดงาน, แบ่งหน้าที่ตามอายุ, อุณหภูมิที่มีความเฉื่อย, ความชื้น/รา, ซากมดถูกขนไปกองขยะ, เหยื่อจากธรรมชาติ, แมงมุม, ฝน + ภาพดิน/ใบไม้/หิน/มดแบบละเอียด, กลางวัน-กลางคืน, ซูม/เลื่อนกล้อง
2. **[x] ทดสอบความเสถียรระยะยาว** (2026-10-10)
   - เลี้ยงดี 1 ปี (autokeep): มดงาน 14 → 78–298 ตัวแล้วแต่ seed, ราชินีรอด; ไม่ดูแลเลย: รังร่วงโรยใน ~75 วัน (รังแห้ง → ไข่ตาย → มดงานตายทีละตัว)
   - ความเร็ว: รัง 500 ตัวที่ 60× ใช้ ~0.6 วินาที/วันในเกม; ก้าวมด ~2.5 µs
   - สิ่งที่แก้ระหว่างทดสอบ: ตารางกลิ่นอาหาร, รายชื่อมดนอกรัง, ฟังก์ชันขยับมดแบบ flat, substep ตอนเร่งเวลา (ผลไม่ลำเอียงตาม substep แล้ว),
     ความชื้นระเหยแบบ exponential + น้ำจากอาหาร, ความทนทานรายตัว, ราชินีถูกป้อนอาหารก่อน, การชักชวน (recruitment), เพดานมดหาอาหาร 20–32%
   - ยังเปิดอยู่: รังขาดโปรตีนบ่อย → กินตัวอ่อนเยอะ (ขึ้นกับการให้อาหารของผู้เล่น), ยังไม่มีฤดูกาล/จำศีล ทำให้โตเร็วกว่าธรรมชาติเล็กน้อย
3. **[~] รังใต้ดิน 3 มิติที่มดขุดเอง** (รุ่นแรกของ 3a + 3b ใช้ได้แล้ว 2026-10-10) (ผู้ใช้ขอ 2026-10-10: ดูได้ 2 มุม = บนพื้นดิน + ภาพตัดขวาง 3 มิติทั้งรัง ซูมได้ เห็นมดขุด)
   - ดินเป็นก้อน voxel (ประมาณ 1 มม./ช่อง) แบ่งชั้น: ดินร่วนผิวบน, ดินเหนียว, ทราย; ความชื้นในดินมีผลต่อความง่ายในการขุด
   - มดขุดทีละเม็ดดิน คาบขึ้นมาทิ้งรอบปากรัง → กองดินบนพื้นผิว (เชื่อมกับภาพด้านบน)
   - กฎการขุดแบบ stigmergy: มดขุดตรงที่มีคนเพิ่งขุด (กลิ่นขุด), ห้องเกิดรอบราชินี/กองตัวอ่อน, อุโมงค์มีแนวโน้มลงล่าง
   - ปริมาตรรังโตตามจำนวนมด (อ้างอิงงานวิจัย Buhl et al. 2004 ที่พบว่ามดขุดจนปริมาตรพอดีกับประชากร); ถ้ารังแน่นเกิน ราชินีวางไข่น้อยลง
   - มดย้ายกองตัวอ่อนไปห้องที่อุณหภูมิ/ความชื้นเหมาะ (กลางวันขึ้นห้องบนที่อุ่น)
   - ภาพ: กล้อง orbit หมุน/ซูม, ระนาบตัด (cutaway) เลื่อนได้เพื่อดูหน้าตัด, มดเป็นโมเดล 3 มิติเล็กๆ (MultiMesh)
   - สลับมุมมอง บนพื้นดิน ↔ ในรัง ด้วยปุ่มเดียว ใช้การจำลองชุดเดียวกัน
   - ผู้ใช้เลือก (2026-10-10): **ทำทั้งสองแบบ** — 3a ก้อนดินธรรมชาติ (ทำก่อน) และ 3b ตู้กระจกแอนท์ฟาร์มแบบแผ่นบาง ให้ผู้เล่นเลือกตอนเริ่มรัง; ใช้ระบบ voxel และการขุดชุดเดียวกัน
   - เทคนิค: voxel 1.5 มม., mesh แบบ surface nets แยก chunk 16³ (สร้างใหม่เฉพาะ chunk ที่ถูกขุด), shader ดินแบบ triplanar + ระนาบตัดที่ระบายหน้าตัดด้วย back-face
   - เสร็จแล้ว: ดิน voxel แบบ z-major + texture 3D ให้หน้าตัด, มดขุดทีละคำแล้วคาบขึ้นไปทิ้งเป็นกองบนผิว, ห้องแบนหลายชั้นต่อกันด้วยปล่อง,
     จำนวนห้องโตตามประชากร, ปริมาตรรังคุมการวางไข่, ดักแด้อยู่ห้องบน/ตัวอ่อนห้องล่าง, ราชินีในห้องของเธอ, มดพักและเดินในรัง,
     ตู้แอนท์ฟาร์มกระจก (เลือกได้จากปุ่ม "เริ่มรังใหม่"), ระนาบตัดเลื่อนได้, หมุน/ซูม/เลื่อนกล้อง
   - ความเร็ว: มุมรัง 3 มิติ ~90–120 FPS (Intel UHD), มุมพื้นดินรัง 500 ตัว ~77 FPS (มดวาดด้วย MultiMesh)
   - v0.3.1: เม็ดดิน/ตัวอ่อนในปากมด, มดในรังมีบทบาทและเดินตามอุโมงค์, พี่เลี้ยงย้ายตัวอ่อนขึ้น-ลงตามอุณหภูมิ
   - v0.3.2: การเคลื่อนไหวนุ่มนวลทั้งสองมุม, ขาก้าวใน 3 มิติ, ขนาดตัวมดตามโภชนาการ/รุ่น nanitic, บันทึกการขุดห้องใหม่
   - v0.3.3: แก้หินทับมด + เลาะขอบหิน, โหมดมองทะลุดิน, ผิวดินโค้งมน (relaxation), โมเดล Lasius niger ละเอียด + LOD
   - v0.3.4: กล้องนุ่มนวล + คีย์บอร์ด + ปุ่มบนจอ + ดับเบิลคลิกโฟกัส, เครื่องมือ "มือ", มองทะลุแบบผนังดินจริง
   - v0.3.5: อนิเมชันส่วนร่างกายบน GPU (shaders/ant.gdshader, ant2d.gdshader) + กิจกรรม: ขุด/ทำความสะอาด/ทักทาย/ป้อนอาหาร/ดูแลตัวอ่อน/รับใช้ราชินี/วางไข่; บนพื้นดินมีเวลาจัดการอาหารและการทักกันบนทาง
   - v0.3.6–0.3.7: ภาพตัดขวางด้านขวาเป็นรังจริง; ความเร็ว 0.5×; เริ่มรังจากราชินีตัวเดียว (claustral founding) เป็นค่าเริ่มต้น
   - ยังเหลือ: ความชื้นในดินแต่ละจุด (ตัวอ่อนตามความชื้น), ตู้แอนท์ฟาร์มหน้าตัดยังเป็นเหลี่ยมบางจุด
   - ค้างไว้ทำทีหลัง (ผู้ใช้ให้ไป PART 4 ก่อน 2026-10-11): ความชื้นในดินแต่ละจุด, หน้าตัดตู้แอนท์ฟาร์มยังเป็นเหลี่ยม
